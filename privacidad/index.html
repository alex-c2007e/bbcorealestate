BBCO Real Estate ("nosotros") es responsable del tratamiento de los datos personales que nos proporcionas. Para cualquier duda sobre este aviso puedes escribirnos a ac4066519@gmail.com.

Datos que recopilamos

Nombre, número de teléfono o WhatsApp, los mensajes que nos envías y la información de las citas que agendas con nosotros (fecha, hora y propiedad de interés).

Para qué usamos tus datos

Uso de servicios de Google

Nuestra aplicación interna utiliza Google Calendar, Google Sheets y Google Drive únicamente para administrar la agenda de citas y los registros de clientes de BBCO Real Estate. La información obtenida a través de las APIs de Google se usa solo para estas funciones, no se vende ni se comparte con terceros y no se utiliza con fines publicitarios. El uso de esta información cumple con la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado.

Con quién compartimos tus datos

No vendemos ni rentamos tus datos personales. Solo los utilizan los proveedores tecnológicos necesarios para operar el servicio (por ejemplo, mensajería y calendario).

Tus derechos (ARCO)

Puedes solicitar el acceso, rectificación, cancelación u oposición al uso de tus datos, así como dejar de recibir mensajes, escribiendo a ac4066519@gmail.com.
